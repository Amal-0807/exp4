# exp4

Flutter experiment 4 - a mileage calculator app with input fields and computed results.

## Use

```
flutter pub add exp4
```

```dart
import 'package:exp4/exp4.dart';

runApp(const MileageApp());
```


## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Open a terminal and run:
   flutter pub get
3. Pick a device (Android phone, emulator, Chrome) from the bottom-right corner.
4. Press F5 or run: flutter run
